## Как открыть локально

Скачай и распакуй репозиторий. Открой `docs/index.html` для русской версии или `docs/en/index.html` для английской. Обе версии работают в браузере без сервера и внешних зависимостей.

## Что попробовать

- Переключить «ТоргСнаб» и группу «Север». Сравнить продукт, текст, кнопку и контактную политику.
- Изменить роль сотрудника или выбрать неизвестную роль.
- На вкладке адаптивного пути попробовать сценарии финансового директора и бухгалтера.
- На вкладке схемы решения посмотреть место предложенных правил в существующем оптимизаторе.

В прототипе четыре синтетических профиля. Суммы, скоры и значения калькулятора иллюстрируют предложенное поведение.

## GitHub Pages

Оба демо опубликованы из ветки `main`, папки `/docs`. Русская страница находится в `docs/index.html`, английская в `docs/en/index.html`.

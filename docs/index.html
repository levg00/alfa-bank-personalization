    Данные → признаки → правила → предложение → канал → метрика

    1. Данные банка

    • CRM: роли, менеджер
    • ИБ: права, события (физлицо + юрлицо)
    • РКО-платежи и контрагенты
    • Связи юрлиц через физлиц
    • ФТС, ЕГРЮЛ
    раз в сутки

    2. Новые признаки

    • Факт. отрасль и сезонность
    • Отрасль группы (≥50% выручки)
    • Роль ЛПР + уверенность
    • Цифровой тип и каналы
    • Концентрация покупателей, ВЭД

    3. Look-alike (как есть)

    • Скор сходства по продукту
    • × конверсия канала × доход
    • + признаки отрасли и структуры

    4. Слой правил

    • Комплаенс-фильтры первыми
    • K отрасли, сезона, структуры
    • K усталости
    • Адресат по роли

    5. Креатив и политика

    • Шаблон «отрасль × роль × продукт»
    • Канал по цифровому типу
    • Частота по физлицу во всей группе

    6. Результат и обучение

    • Клик, расчёт, заявка
    • A/B + holdout 10%
    • Реакции → признаки на следующий день

# Прототип команды «Первые»

`index.html` — исходный прототип команды, сохранённый без изменений. Он работает локально без сервера и внешних зависимостей.

## Как открыть

Скачайте репозиторий через **Code → Download ZIP**, распакуйте его и откройте `docs/index.html` в браузере. Просмотр HTML-кода на GitHub не запускает приложение.

## Что попробовать

1. На вкладке «Профиль → предложение» выберите «ТоргСнаб · S1», затем «Группа “Север” · S2».
2. Сравните продукт, текст, кнопку и контактный сценарий в колонках AS IS и TO BE.
3. Измените роль сотрудника или выберите отсутствие данных о ней.
4. На вкладке «Адаптивный путь в ИБ» попробуйте сценарии финансового директора и бухгалтера.
5. На вкладке «Схема решения» посмотрите место новых правил в существующей архитектуре.

## Публичное демо через GitHub Pages

В настройках репозитория: **Settings → Pages → Deploy from a branch → main → /docs → Save**. После публикации GitHub покажет адрес демо. Его можно поставить в README вместо ссылки на эту папку.

## Что демонстрирует прототип

Изменение профиля меняет ранжирование и представление предложения, а действия пользователя переключают сценарии интерфейса. Четыре профиля, суммы, модельные скоры и коэффициенты заданы для демонстрации.

Это не подключённая банковская система или обученная командой ML-модель. Цифры калькулятора иллюстративны; контактные лимиты показаны как логика концепции. Часть подписей в исходной версии отличается от позднего пересчёта — см. `analysis/presentation-reconciliation.csv`.

## Open locally

Download and extract the repository. Open `docs/en/index.html` for English or `docs/index.html` for Russian. Both versions work in a browser without a server or external dependencies.

## What to try

- Switch between TorgSnab and Sever Group. Compare the product, wording, action button and contact policy.
- Change the employee role or select an unknown role.
- Open Adaptive banking journey and try the CFO and accountant scenarios.
- Open Solution architecture to see where the proposed rules fit into the existing optimizer.

The prototype uses four synthetic customer profiles. Amounts, scores and calculator values illustrate the proposed behavior.
